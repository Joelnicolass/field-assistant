# Referencias visuales

Acá van las capturas que sirven de referencia para `VISUAL.md`.

1. Copiá las capturas a esta carpeta, con un nombre que diga qué muestran (por ejemplo
   `inicio.png`, `tarjeta-lluvia.png`, `orbe-grabando.png`).
2. Corré `/create-visual-guide` y decile que use esta carpeta.

`VISUAL.md` tiene que dejar escrito, además de lo que pide el comando:

- **Los valores del tema**: colores, tipografía, tamaños de letra, espaciados, radios y
  sombras. De ahí sale el tema del design system; ningún componente escribe estos valores a
  mano.
- **Las pantallas y estados cubiertos**: inicio, cada tarjeta, y el orbe en sus cuatro estados.
- **Qué se toma de cada captura** y qué no.
